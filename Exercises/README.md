
# Python Exercises

This folder contains small Python programs and practice projects created while learning and practicing Python.

## 📚 Exercises

### 🏦 Banking Program

A simple banking program that demonstrates basic user interaction, deposits, withdrawals, and balance management.

### 🍿 Concession Stand

A simple concession stand program that demonstrates menus, user input, item selection, quantities, and basic calculations.

### 🎲 Number Guessing Game

A random number guessing game where the user tries to guess a randomly generated number.

### ✊ Stone, Paper, Scissors

A simple Stone, Paper, Scissors game using user input and Python's `random` module.

### 🧮 Basic Calculator

A simple calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.





## 🎯 Purpose

These programs are practice projects created while learning Python fundamentals and improving programming logic.
